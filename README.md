# qingqi

MEMS半导体氢气传感器数据计算与泄漏判断网页。

## 使用方法

直接使用浏览器打开 `。项目不需要安装依赖，也不需要连接网络。

1. 在“传感器参数”中填入实际分压电路、`Vc`、`RL`、`R0`、标定系数、补偿参数和报警条件。
2. 手动录入采样值，或导入CSV文件。
3. 查看计算出的 `Rs`、`Rs/R0`、氢气浓度、`%LEL` 和泄漏判断结果。
4. “模拟”模式只用于演示界面与状态变化。

## CSV格式

至少包含以下列：

```csv
vout,temperature,humidity
2.500,25.0,50.0
```

完整支持的列为：

```csv
timestamp,vout,temperature,humidity,heaterVoltage,heaterCurrent,interval
```

项目内的 `sample-data.csv` 可直接导入测试。

## 计算模型

当前浓度模型为：

```text
Rs/R0 = A × C^(-B)
C = (A / correctedRatio)^(1/B)
```

温湿度补偿暂采用线性演示模型。正式使用时，应根据传感器厂家的标定表替换为查表或拟合模型。

## 安全说明

默认参数仅用于演示，不能作为实际产品的报警依据。本工具用于算法验证和数据分析，不得单独承担安全联锁。正式投用前必须完成标准氢气标定、温湿度试验、交叉气体测试、老化漂移测试、故障诊断和适用的产品认证。
